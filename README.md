# Центр речи «Будущее» — редизайн в стиле claymorphism

Тестовая копия: https://pizko.github.io/logo/ (закрыта от индексации, без Метрики).
Боевой сайт: https://лого-будущее.рф

```
src/                      # сайт для боевого домена (Метрика, индексация — как было)
src/assets/css/clay.css   # стиль главной: пластилиновые поверхности, тени, кнопки с толщиной
src/assets/css/clay-pages.css  # тот же стиль для внутренних страниц (подключается последним)
src/assets/clay/sprite.svg     # набор объектов из пластилина: буквы, кубик, звезда, книга…
tools/make_home.py        # собирает src/index.html (тексты и диалоги — из исходной главной)
tools/style_pages.py      # подключает clay-pages.css к внутренним страницам
build.py                  # src/ → docs/ для GitHub Pages
```

Все объекты рисуются одним SVG-фильтром `#clay`: тень вниз, светлая кромка сверху,
тёмная снизу и матовое зерно — поэтому выглядят как один материал.
